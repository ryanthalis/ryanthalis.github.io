# Ryan Thalis — Personal Website

A responsive, accessible personal portfolio built with plain HTML and CSS.

## See it locally

Open `dist/index.html` directly in a browser. For automatic refresh while editing, install the **Live Server** VS Code extension, right-click `dist/index.html`, and choose **Open with Live Server**.

## Where things live

- `dist/index.html` contains the page content and semantic structure.
- `dist/styles.css` contains the colours, layout, responsive design, and visual effects.
- `.openai/hosting.json` tells the hosting service to publish the `dist` folder.

No React, JavaScript, package installation, or build step is required.
